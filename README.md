# Customer Segmentation & Churn Prediction (Machine Learning)

End-to-end data science project on an e-commerce customer base: **RFM segmentation with K-Means** and **churn prediction** with scikit-learn.

> Dataset: synthetic (5,000 customers, ~32,000 orders), generated by `src/generate_data.py` for portfolio purposes.

## Approach
1. **Data preparation** (Pandas): RFM features (recency, frequency, monetary), average basket, return rate. Only orders older than 90 days are used as features, so the churn window does not leak into the model.
2. **Segmentation** (K-Means): number of clusters chosen with the silhouette score (best k = 3, silhouette 0.44).
3. **Churn prediction**: Logistic Regression vs Random Forest in a scikit-learn `Pipeline` (scaling + one-hot encoding), stratified train/test split, ROC-AUC.

## Results
| Model | ROC-AUC |
|---|---|
| Logistic Regression | 0.777 |
| **Random Forest** | **0.786** |

| Segment | Customers | Median spend (EUR) | Churn rate |
|---|---|---|---|
| Loyal customers | 2,809 | 257 | 23% |
| At-risk one-time buyers | 1,631 | 56 | **60%** |
| New customers | 560 | 0 | 18% |

**Business takeaway:** one-time buyers who have not ordered for several months churn at 60%; they are the priority target for a re-activation campaign.
